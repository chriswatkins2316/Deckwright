Claude

Building and evaluating decks uses your own Anthropic API key. It is stored only on this device and is only ever sent to Anthropic.

Create a key at console.anthropic.com under API Keys. Setting a monthly spend limit there is a good idea. A deck build usually costs a few cents to about 15 cents, more on the Deep setting.

Backup

Your collection and saved decks are stored on this device only. A backup file lets you move them to another phone or computer, or keep them safe.

Install on your phone

Android: in Chrome, tap ⋮ then Install app (or Add to Home screen).
iPhone: in Safari, tap Share then Add to Home Screen.

Once installed it opens full screen and works offline. Claude, card pictures and card updates need a connection.
