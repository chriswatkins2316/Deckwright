Deck records

Claude

Building and evaluating decks uses your own Anthropic API key. It is stored only on this device and is only ever sent to Anthropic.

Create a key at console.anthropic.com under API Keys. Setting a monthly spend limit there is a good idea. A deck build usually costs a few cents to about 15 cents, more on the Deep setting.

Automatic weekly updates

A job in your GitHub repository refreshes the cards, prices and combos every Monday. To run it now: open your repository on GitHub, tap Actions, pick Update card and combo data, then Run workflow. Give it a few minutes, then open the app twice.

Adds newly printed cards and picks up ban list changes and Standard rotation. Takes about 20 seconds.

Sync between devices

Keeps your collection, decks, wishlist, card places, prices and records the same on every device, using a private GitHub Gist on your own GitHub account.

Make a token at github.com/settings/tokens/new with only the gist box ticked, and use the same token on each device. It stays on the device and is only sent to GitHub.

Backup

Your collection and saved decks are stored on this device only. A backup file lets you move them to another phone or computer, or keep them safe.

Install on your phone

Android: in Chrome, tap ⋮ then Install app (or Add to Home screen).
iPhone: in Safari, tap Share then Add to Home Screen.

Once installed it opens full screen and works offline. Claude, card pictures and card updates need a connection.
